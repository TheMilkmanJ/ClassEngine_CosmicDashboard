## 3. Add publications (pick one primary path)

### Path A — Claim from Web of Science (best when papers are already indexed)

1. Researcher Profile → **Add publications** / **Claim publications**.
2. Search by **DOI**, title, or your name variants.
3. Claim only items that are **yours** (check coauthor list).
4. Merge duplicates if the system offers it.

### Path B — Import via ORCID

1. Ensure ORCID has works (DOI add, Crossref search, or BibTeX/RIS import on ORCID).
2. Sync ORCID → WoS Researcher Profile.
3. Review claimed list for missing DOIs.

### Path C — Manual / file import

1. Profile → **Add publications** → import **RIS / BibTeX** if available.
2. Or add by **DOI** one-by-one (most reliable for preprints vs published).

**For PRTOE / arXiv only:** if not yet indexed in WoS Core Collection, the paper may **not** appear in Core search. Still:

- Put the arXiv / DOI on **ORCID** (visibility: Everyone or Trusted parties).
- Add to WoS profile when the published version gets a DOI and indexing lag clears (often weeks–months after journal DOI).

## 4. Name + affiliation hygiene (stops split profiles)

1. **Preferred name** + all **name variants** (e.g. with/without middle initial).
2. **Primary affiliation** (current) + past orgs if relevant.
3. Institutional email if you have one (helps claim matching).
4. Mark **primary** affiliation so metrics don’t fragment.
