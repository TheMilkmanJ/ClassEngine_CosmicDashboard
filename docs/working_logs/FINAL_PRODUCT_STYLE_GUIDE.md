# Final-product style guide (working log)

**Audience:** writers and currency agents editing living docs under `docs/`.  
**Not** a physics claim surface. Instructions live here so living files carry only present facts.

## Chain-currency prose

1. **Quote R−1 with N and timestamp** (not date alone). Current value + N + t + ratio-to-stop + `converged` is the whole fact.
2. **Do not freeze permanent direction adjectives** on noisy R−1 trajectories (e.g. “nearest-and-receding forever,” “improving toward gate,” “nearly there / ~1.18× closest”). Direction language goes stale between checkpoints.
3. **Do not** treat temporary R−1 < stop without sampler self-stop as bookable.
4. **Do not** embed “was X@N=…; earlier Y@…” chains as living status — pure repair log. History belongs in package notes or the failures ledger when it matters for process.
5. Route-D (and other early instruments): quote current R−1 + N + t + ×stop; do **not** freeze “stuck at 103” (or any prior plateau) as permanent status.

## Withdrawals and corrections

- **Restate positively.** If stripping past-tense repair still leaves a claim, keep the claim in the present tense with no reference to what it replaced.
- **History →** [`PRTOE_FAILURES_LEDGER.md`](../PRTOE_FAILURES_LEDGER.md) or a working_logs package note — not the living paragraph.
- **Do not delete** a finding that is itself the current claim (e.g. mass grade = onset clock + at most one unresolved check).

## INDEX / refuse-lists

- “Must not claim” columns keep **permanent refuse facts** only (e.g. Booked H₀ / Σm_ν / S₈; peek-book; GR-as-gate).
- Editor framing bans (“nearest-and-receding forever,” “routeD stuck at 103”) live **here**, not as refuse-list status.

Other living files may still carry older copies until a separate currency sweep; when editing those files, move the instruction here and leave only the present fact.
