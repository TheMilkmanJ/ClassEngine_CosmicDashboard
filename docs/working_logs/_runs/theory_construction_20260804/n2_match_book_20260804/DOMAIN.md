## 2. Phase I domain (metric-ON approach)

### Applies when

| # | condition |
|---|---|
| I-1 | Emergent metric defined: characteristic scales \(\gg\xi\) |
| I-2 | Near-homogeneous enough for FRW or shear-corrected Bianchi exterior |
| I-3 | Preferred-frame fluid description valid |
| I-4 | Acoustic map: long-wavelength modes \(x=k\xi\ll 1\) for metric trust |

### Maps allowed

- Forward: \((n,v,c_s)\to g_\mathrm{acoustic}\)  
- Inverse F-A1 (medium sector) on preferred slice  
- \(H_\mathrm{kin}=\langle\Theta\rangle_\mathrm{phys}/d\) as exterior expansion estimate when I-1…I-3 hold  
- Friedmann / shear-corrected constraint

### Fails when

| fail | consequence |
|---|---|
| Scales \(\to\xi\) (\(R_H\sim\sqrt{3}\,\xi\) door) | leave Phase I → Phase II; stop exterior \(H\) |
| Strong inhomogeneity / mixmaster chaos | FRW map fails; anisotropic bookkeeping only (M2 partial) |
| \(x\gtrsim 1\) modes dominate exterior claim | metric description ends (FA1 \(v_g>c_s\)) |
| Homogeneous average only, seeking turn | stress channel killed; no medium bounce from homog |

### Door boundary

At shear door \(H_\mathrm{door}=1/(\sqrt{3}\,\xi)\), Phase I **ends**. Numbers:

- \(c_s\approx 0.14796\)  
- \(|H_\mathrm{kin}(\Theta=1,d=3)|/H_\mathrm{door}\approx 0.08542\)  
- \(\rho_\mathrm{eff}^{1/4}\approx 2.827\,\mathrm{keV}\) (door)
