# Sigma-mnu public form freeze (2026-08-06)

Purpose: stop forward-facing shelf drift between bare `61.3 meV` and bare `61.4 meV` when the
corpus is talking about the same neutrino-floor relation.

## Public form

Use:

- prose / shelf shorthand: `Σm_ν ≈ 61.35 meV, normal ordering`
- exact public band when the number itself matters: `Σm_ν = 61.34–61.37 meV`

## Why this is the right surface form

- the common/public anchor set already used across the shelf lands in the `61.34–61.37 meV` band
- the low/high anchor checks recorded in the registry material give `61.35–61.40 meV`
- bare `61.3` and bare `61.4` were both being used as shorthand for the same relation, which is a
  process problem, not a physics disagreement

## Rules

- do **not** use bare `61.3 meV` or bare `61.4 meV` in forward-facing docs for the shared relation
  unless the file is explicitly discussing a historical quote or an anchor-specific computation
- use the exact band when writing falsifier clauses, referee rows, or side-by-side comparisons
- use the shorthand `≈61.35 meV` in prose and overview tables
- this freezes only the **surface form**; it does **not** promote the live bbnfix pair to a booked
  joint posterior
