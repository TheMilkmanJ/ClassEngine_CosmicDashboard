## Status values

| tag | meaning |
|---|---|
| **COMPLETE** | Document has finished its job; residue is optional or already paid |
| **COMPLETE-ABSTENTION** | Finished by deliberately refusing the problem (jurisdiction silence) |
| **COMPLETE-CONDITIONAL** | Finished at its named grade; conditionals are explicit, not papered over |
| **OPEN-DESK** | Residue closable at the desk without MCMC or new mechanisms |
| **OPEN-MACHINE** | Residue waits on a chain, sim, or sampler (not on desk invention) |
| **OPEN-THEORY** | Residue is a real mechanism/derivation (do not mark COMPLETE) |
| **WATCH-EXTERNAL** | Residue waits on external data, facilities, or literature campaigns |
| **LEDGER/HISTORY** | Process, registry, index, or living map — complete as a *record* |

A file may carry a primary tag and a parenthetical secondary (e.g. COMPLETE-CONDITIONAL +
WATCH-EXTERNAL) when both apply; the primary is what the inventory counts.
